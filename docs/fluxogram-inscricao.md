# Fluxograma de Inscrição em Curso

## Processo

1. Aluno acessa a plataforma.
2. Aluno faz login.
3. Sistema verifica os dados.
4. Se os dados estiverem incorretos, o sistema solicita novamente o login.
5. Se estiverem corretos, o aluno acessa o catálogo de cursos.
6. Aluno escolhe um curso.
7. Sistema apresenta os detalhes do curso.
8. Aluno solicita a inscrição.
9. Sistema confirma a inscrição.
10. Aluno passa a ter acesso ao curso.
